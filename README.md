# Задание 4. Массивы

Массивы создаются динамически (new int[length]) и освобождаются оператором delete[]. Длина массива передаётся в функции отдельным параметром, потому что при передаче в функцию массив превращается в указатель и теряет информацию о размере.


## Задача 1. Поиск первого значения

### Текст задачи

Дана сигнатура функции: int findFirst (int arr[], int x);

Необходимо реализовать функцию таким образом, чтобы она возвращала индекс первого вхождения числа x в массив arr. Если число не входит в массив – возвращается -1.

Пример:  
arr=[1, 2, 4, 2, 2, 5]

### Алгоритм решения

Массив просматривается слева направо. Как только встречается элемент, равный искомому числу, возвращается его индекс, поэтому найденная позиция — это первое вхождение. Если просмотр закончился без совпадений, возвращается -1.

## Задача 5. Добавление массива в массив

### Текст задачи

Необходимо реализовать функцию таким образом, чтобы она возвращала новый массив, который будет содержать все элементы массива arr, однако в позицию pos будут вставлены значения массива ins.

Исходные массивы не изменяются.
